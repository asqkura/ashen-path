# 属性設計メモ

## 目的
- 各属性の役割を先に定義して、今後カードを追加するときの方向性をぶらさない
- ダメージ量だけで差別化せず、プレイ感と戦術で属性ごとの個性を出す

## 前提
- 現在の属性は `炎 / 氷 / 風 / 光 / 闇` と `無属性`
- 敵は弱点属性を2種類持つ
- 弱点属性で攻撃するとシールドを削り、シールドが0になると Break する

## 属性の役割

### 無属性
- 役割: 安定
- 特徴: 弱点を突けない代わりに、どの状況でも使いやすい
- 方向性:
  - 基本ダメージ
  - 低コスト
  - 手札事故の保険
  - 単純で分かりやすい効果

### 炎
- 役割: 高火力
- 特徴: コストは重めだが、1枚あたりのリターンが大きい
- 方向性:
  - 高ダメージ
  - 使い切り
  - 条件付きでさらに火力上昇
  - Break中の追撃向き

### 氷
- 役割: 制御
- 特徴: 直接火力だけでなく、敵の行動やテンポに干渉する
- 方向性:
  - 中ダメージ
  - 敵の強化解除
  - 次の敵行動を弱める
  - Breakを取りにいく安定札

### 風
- 役割: 手数
- 特徴: 軽くて回しやすく、連続使用やSP効率に寄る
- 方向性:
  - 低コスト
  - 複数回攻撃
  - 追加ドロー
  - 連続使用で強くなる

### 光
- 役割: 支援
- 特徴: 攻撃しつつ立て直しや補助ができる
- 方向性:
  - 回復
  - シールド回復
  - SP補助
  - 次カード強化

### 闇
- 役割: リスクと爆発力
- 特徴: 強いが、何かを消費したり代償を伴う
- 方向性:
  - 高ダメージ
  - HP消費
  - 手札破棄
  - 使い切り
  - 条件達成時の大きい見返り

## ざっくりした棲み分け
- 無属性: 困ったときの基準札
- 炎: 重いが強い
- 氷: 崩しと妨害
- 風: 軽くて回る
- 光: 維持と補助
- 闇: 危険だが最大値が高い

## カード追加時の指針
- 1属性につき最低でも以下を用意したい
- 基本カード: その属性らしさが一番分かりやすい1枚
- 強化カード: コストや条件が重い代わりに個性が強い1枚
- 補助カード: ダメージ以外の役割を持つ1枚

## 避けたいこと
- 全属性が「色違いのダメージカード」になること
- 低コスト高火力が複数属性に散ること
- 強い属性と弱い属性の役割が丸被りすること

## 次に決めるとよい項目
- 各属性のキーワード
- 各属性の基本カード2枚
- 各属性のレア枠カード1枚
- 光と闇にどこまで補助/代償要素を持たせるか
