# カードリスト

現在の `card-catalog.json` に合わせた一覧ぬめ。

## 無属性

- アタック (SP: 1) / 敵単体に5ダメージを与える。
- チェイン (SP: 1) / 敵単体に3ダメージを与える。次に使用するカードのダメージを+3する。
- リカバー (SP: 0) / SPを1回復する。
- ドロー (SP: 1) / 山札からカードを2枚引く。
- ブレイブ (SP: 1) / 次に使用するカード1枚のSPコストを-1する（最小0）。
- ラッシュ (SP: 2) / 敵単体に3ダメージを2回与える。
- ピアス (SP: 2) / 敵単体に6ダメージを与える。次に使用するカード1枚のSPコストを-1する。
- スマッシュ (SP: 3) / 敵単体に12ダメージを与える。
- フィニッシュ (SP: 3) / 敵単体に15ダメージを与える。3枚目のカードならさらに10ダメージを与える。
- スラッシュ (SP: 2) / 敵単体に8ダメージを与える。

## 炎属性

- ヒート (SP: 1) / 敵単体に4ダメージを与える。以後の炎カードのダメージを+1する。
- スパークフレア (SP: 1) / 敵単体に3ダメージを与える。次に使用する【炎】カードのSPコストを-1する。
- ブレイズ (SP: 2) / 敵単体に8ダメージを与える。
- バーンアップ (SP: 2) / このバトル中、自分の炎カードのダメージを+4する。
- イグニッション (SP: 1) / 敵単体に5ダメージを与える。このターンに使用した2枚目以降のカードならダメージを2倍にする。
- フレア (SP: 3) / 敵単体に15ダメージを与える。
- インフェルノ (SP: 4) / 敵単体に18ダメージを与える。HPが半分以下ならダメージを1.5倍にする。
- アッシュ (SP: 2) / 敵単体に10ダメージを与える。自身の墓地（または除外）にある【使い切り】カードを1枚手札に戻す。
- マグマバースト (SP: 4) / 敵単体に25ダメージを与える。
- ボルカノ (SP: 5) / 敵単体に22ダメージを与える。熾火1につきさらに2ダメージを与える。

## 氷属性

- スノウ (SP: 1) / 敵単体に4ダメージを与える。
- コールドミスト (SP: 1) / 敵に凍結を2付与する。
- アイスエッジ (SP: 1) / 敵単体に6ダメージを与える。敵に凍結を1付与し、次の攻撃を2下げる。
- フロスト (SP: 2) / 敵単体に10ダメージを与える。
- フリーズ (SP: 2) / 敵単体に4ダメージを与える。敵に凍結を3付与する。
- アイスウォール (SP: 2) / 自身にガード8を付与する。
- ハッシュ (SP: 2) / 敵に凍結を2付与する。敵の次の攻撃を4下げ、カードを1枚引く。
- ブリザド (SP: 3) / 敵単体に14ダメージを与える。
- クリスタル (SP: 3) / 敵単体に10ダメージを与える。自身にガード4を付与し、カードを1枚引く。
- グレイシャ (SP: 4) / 敵単体に15ダメージを与える。敵に凍結を2付与する。
- アバランチ (SP: 5) / 敵単体に20ダメージを与える。敵に凍結を2付与する。

## 風属性

- ウィンド (SP: 1) / 敵単体に3ダメージを与える。このターン最初の風カードなら、カードを1枚引く。
- ガスト (SP: 1) / 敵単体に5ダメージを与える。
- ブリーズ (SP: 1) / このターン最初の風カードなら、カードを1枚引く。
- ステップ (SP: 1) / このターンの間、自身の手札にあるすべてのカードのSPコストを-1する（最小0）。
- エアロ (SP: 2) / 敵単体に9ダメージを与える。
- ラピッド (SP: 2) / 敵単体に5ダメージを2回与える。
- サイクロン (SP: 2) / 敵単体に7ダメージを与える。このターン最初の風カードなら、カードを1枚引く。
- フェザー (SP: 1) / 自身の手札を1枚捨てる。山札からカードを3枚引く。
- テンペスト (SP: 3) / 敵単体に16ダメージを与える。
- ゼファー (SP: 3) / 敵単体に5ダメージを与える。このターンに使用した【風】カードの枚数分、この効果を繰り返す。

## 光属性

- ライト (SP: 2) / 敵単体に10ダメージを与える。
- ガイド (SP: 1) / 啓示を得る。
- ルミナ (SP: 1) / 敵単体に5ダメージを与える。自身のHPを3回復し、啓示を得る。
- シャイン (SP: 2) / 敵単体に8ダメージを与える。【啓示】なら、次に使うカード1枚のダメージを+4する。
- レイ (SP: 2) / 敵単体に12ダメージを与える。【啓示】なら、次に使うカード1枚のダメージを+3する。
- ヒールライト (SP: 2) / 自身のHPを10回復する。
- バリア (SP: 2) / 自身にガード5を付与し、啓示を得る。
- シェルター (SP: 2) / 自身にガード9を付与し、HPを4回復する。啓示を得る。
- サンライト (SP: 4) / 敵単体に18ダメージを与える。与えたダメージの50%分、自身のHPを回復する。【啓示】なら、次に使うカード1枚のダメージを+6する。
- ホーリー (SP: 3) / 敵単体に20ダメージを与える。【啓示】なら、次に使うカード1枚のダメージを+5する。
- ジャッジ (SP: 4) / 敵単体に24ダメージを与える。啓示を得る。

## 闇属性

- シャドウ (SP: 2) / 敵単体に11ダメージを与える。
- サクリファイス (SP: 0) / 自身のHPを5消費する。SPを2回復する。
- クロウ (SP: 1) / 敵単体に4ダメージを与える。次に使用する【闇】カードのダメージを1.5倍にする。
- ダーク (SP: 2) / 敵単体に11ダメージを与える。
- グリム (SP: 1) / 自身の手札をすべて捨てる。捨てた枚数×5ダメージを敵単体に与える。
- ナイト (SP: 3) / 敵単体に18ダメージを与える。
- ノクス (SP: 2) / 敵単体に10ダメージを与える。【協約】ならダメージを3倍にする。
- アビス (SP: 4) / 敵単体に22ダメージを与える。自身のHPを3消費する。【協約】ならカードを1枚引く。
- イクリプス (SP: 5) / 敵単体に35ダメージを与える。
- リーパー (SP: 4) / 敵単体に28ダメージを与える。【協約】ならさらに12ダメージを与える。
