# カードリスト案

## 方針
- [attribute-design.md](/c:/Unity/Ashen_Path/Docs/attribute-design.md) の役割定義に沿って作る
- 各属性ごとに「基本」「強化」「特殊」を混ぜる
- ここでは実装前提の素案として、効果の方向性を先に決める

## 実装優先候補

### 最初に入れたいカード
- 無属性: アタック / ガードブレイク / ドロー
- 炎: ブレイズ / フレア / バーンアップ
- 氷: フロスト / フリーズ / アイスウォール
- 風: ガスト / ラピッド / ブリーズ
- 光: レイ / ヒールライト / ルミナ
- 闇: シャドウ / サクリファイス / リーパー

### 今の実装に乗せやすいカード
- 単純ダメージ
- 使い切り
- 複数回攻撃
- SP回復
- ドロー
- 次カード強化

### 後で仕組みが必要なカード
- 敵の次行動を弱める
- 手札破棄
- シールド削り値増加
- Break中追加効果
- 条件付きダメージ上昇
