# カードリスト

コピーしてそのまま使えるように、全属性のカードリストをカテゴリごとにまとめたぬめ。
このまま開発資料やメモ帳に貼り付けて活用してほしいぬめ。

## 無属性 (Normal)

- アタック (SP: 1) / 敵単体に5ダメージを与える。
- チェイン (SP: 1) / 敵単体に3ダメージを与える。次に使用するカードのダメージを+3する。
- リカバー (SP: 0) / 【使い切り】SPを1回復する。
- ドロー (SP: 1) / 山札からカードを2枚引く。
- ブレイブ (SP: 1) / 次に使用するカード1枚のSPコストを-1する（最小0）。
- ラッシュ (SP: 2) / 敵単体に3ダメージを2回与える。
- ガードブレイク (SP: 2) / 敵単体に4ダメージを与える。敵の【シールド】値を2減少させる。
- スマッシュ (SP: 3) / 敵単体に12ダメージを与える。
- フィニッシュ (SP: 3) / 敵単体に15ダメージを与える。対象が【Break】中ならダメージを2倍にする。
- スラッシュ (SP: 2) / 敵単体に8ダメージを与える。

## 炎属性 (Fire)

- ヒート (SP: 1) / 敵単体に4ダメージを与える。次に使用する【炎】カードのダメージを+2する。
- スパークフレア (SP: 1) / 敵単体に3ダメージを与える。次に使用する【炎】カードのSPコストを-1する。
- ブレイズ (SP: 2) / 敵単体に8ダメージを与える。
- バーンアップ (SP: 2) / このターンの間、自身が使用するすべての【炎】カードのダメージを+4する。
- イグニッション (SP: 1) / 敵単体に5ダメージを与える。このターンに使用した2枚目以降のカードならダメージを2倍にする。
- フレア (SP: 3) / 敵単体に15ダメージを与える。
- インフェルノ (SP: 4) / 敵単体に18ダメージを与える。自身のHPが最大値の半分以下ならダメージを1.5倍にする。
- アッシュ (SP: 2) / 敵単体に10ダメージを与える。自身の墓地（または除外）にある【使い切り】カードを1枚手札に戻す。
- マグマバースト (SP: 4) / 【使い切り】敵単体に25ダメージを与える。
- ボルカノ (SP: 5) / 敵単体に30ダメージを与える。対象が【Break】中ならダメージをさらに+20する。

## 氷属性 (Ice)

- スノウ (SP: 1) / 敵単体に4ダメージを与える。
- コールドミスト (SP: 1) / 敵の【シールド】値を2減少させる。
- アイスエッジ (SP: 1) / 敵単体に6ダメージを与える。敵の次ターンの攻撃力を-3する。
- フロスト (SP: 2) / 敵単体に10ダメージを与える。
- フリーズ (SP: 2) / 敵単体に4ダメージを与える。敵が次に行う行動の最終ダメージを半減させる。
- アイスウォール (SP: 2) / 自身に【シールド】8を付与する。
- ブリザド (SP: 3) / 敵単体に14ダメージを与える。
- クリスタル (SP: 3) / 敵単体に10ダメージを与える。自身に【シールド】4を付与し、カードを1枚引く。
- グレイシャ (SP: 4) / 敵単体に15ダメージを与える。敵の【シールド】値を4減少させる。
- アバランチ (SP: 5) / 【使い切り】敵の【シールド】をすべて破壊し、20ダメージを与える。

## 風属性 (Wind)

- ウィンド (SP: 1) / 敵単体に3ダメージを与える。山札からカードを1枚引く。
- ガスト (SP: 1) / 敵単体に5ダメージを与える。
- ブリーズ (SP: 1) / 山札からカードを2枚引く。
- ステップ (SP: 1) / このターンの間、自身の手札にあるすべてのカードのSPコストを-1する（最小0）。
- エアロ (SP: 2) / 敵単体に9ダメージを与える。
- ラピッド (SP: 2) / 敵単体に5ダメージを2回与える。
- サイクロン (SP: 2) / 敵単体に7ダメージを与える。山札からカードを1枚引く。
- フェザー (SP: 1) / 自身の手札を1枚捨てる。山札からカードを3枚引く。
- テンペスト (SP: 3) / 敵単体に16ダメージを与える。
- ゼファー (SP: 3) / 敵単体に5ダメージを与える。このターンに使用した【風】カードの枚数分、この効果を繰り返す。

## 光属性 (Light)

- ライト (SP: 2) / 敵単体に10ダメージを与える。
- ガイド (SP: 1) / 次に使用するカード1枚のダメージを+5する。
- ルミナ (SP: 1) / 敵単体に5ダメージを与える。自身のHPを3回復する。
- シャイン (SP: 2) / 敵単体に8ダメージを与える。自身のHPが最大値ならダメージを2倍にする。
- レイ (SP: 2) / 敵単体に12ダメージを与える。
- ヒールライト (SP: 2) / 自身のHPを10回復する。
- バリア (SP: 2) / 自身に【シールド】5を付与する。このターン、自身へのデバフを無効化する。
- サンライト (SP: 4) / 敵単体に18ダメージを与える。与えたダメージの50%分、自身のHPを回復する。
- ホーリー (SP: 3) / 敵単体に20ダメージを与える。
- ジャッジ (SP: 4) / 【使い切り】敵単体に「自身の現在HP」と同値のダメージを与える。

## 闇属性 (Dark)

- シャドウ (SP: 2) / 敵単体に11ダメージを与える。
- サクリファイス (SP: 0) / 自身のHPを5消費する。SPを2回復する。
- クロウ (SP: 1) / 敵単体に4ダメージを与える。次に使用する【闇】カードのダメージを1.5倍にする。
- ダーク (SP: 2) / 敵単体に11ダメージを与える。
- グリム (SP: 1) / 自身の手札をすべて捨てる。捨てた枚数×5ダメージを敵単体に与える。
- ナイト (SP: 3) / 敵単体に18ダメージを与える。
- ノクス (SP: 2) / 敵単体に10ダメージを与える。自身の手札がこのカード1枚のみの場合、ダメージを3倍にする。
- アビス (SP: 4) / 敵単体に22ダメージを与える。自身のHPを3消費し、このカードを自身の【墓地】ではなく【手札】に戻す。
- イクリプス (SP: 5) / 【使い切り】敵単体に35ダメージを与える。
- リーパー (SP: 4) / 敵単体に40ダメージを与える。発動条件: 対象が【Break】中。発動後、自身のHPを1にする。
