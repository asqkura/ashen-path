# キーワード能力

カードテキストを短く保ちつつ、属性ごとの役割を分かりやすくするための共通キーワードぬめ。

## 一覧

- `火種 X`
  炎属性。次に使う炎カード1枚のダメージを `+X` するぬめ。
- `凍結 X`
  氷属性。敵の次の攻撃力を `-X` するぬめ。
- `凍結`
  氷属性。敵の次の攻撃を大きく弱める特殊な凍結表記ぬめ。
- `追風`
  風属性。このカードを使った時、追加でカードを引くぬめ。
- `祝福`
  光属性。自分のHPが最大なら、このカードの数値効果を強化するぬめ。
- `協約`
  闇属性。リスクや条件を満たしたときに追加効果が発動する闇系の総称ぬめ。
- `消滅`
  共通。使ったらそのバトル中は除外されるぬめ。

## 運用方針

- キーワードはまず「表示と整理」のために使うぬめ。
- 既存のカード効果ロジックは維持しつつ、カード本文ではキーワードを優先して見せるぬめ。
- 将来的に `JSON` 上の `keywords` を見て自動説明文やツールチップを出せる形を目指すぬめ。
