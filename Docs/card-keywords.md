# カードキーワード

現在の戦闘ルールで使っているキーワードの意味をまとめたぬめ。

## 熾火 X

- このバトル中、自分の炎カードのダメージを `+X` するぬめ

## 凍結 X

- 敵に凍結を `X` 付与するぬめ
- 凍結が `5` 以上になると、次の敵行動をスキップして凍結をリセットするぬめ

## 追風

- このターン最初の風カードなら、カードを `1` 枚引くぬめ

## 啓示

- 次に使う `祝福` 持ちカードの追加効果を有効にするぬめ

## 祝福 X

- 直前のカードで `啓示` を得ていた場合、その `祝福` 持ちカード自身の追加効果が発動するぬめ

## 協約

- このターン中に自分がHPを失っていた場合、カードごとの追加効果が有効になるぬめ

## 消滅

- 使ったらそのバトル中は除外されるぬめ
